# 🧩 C++ SFML Tetris

A modern, arcade-style Tetris game built from scratch in **C++** using the **SFML 3** library.

## 🕹️ Controls
- **Left / Right Arrow**: Move piece horizontally
- **Up Arrow**: Rotate piece
- **Down Arrow**: Soft drop
- **Spacebar**: Hard drop
- **R**: Restart (after Game Over)

## 🛠️ Prerequisites & Dependencies
To compile and run this game on Linux, you need **SFML 3** and the audio backend packages installed:
```bash
sudo apt update
sudo apt install libflac-dev libogg-dev libvorbis-dev libopenal-dev
